# SEO 中控系统

面向海外 B2B 独立站的本地 SEO 内容工作台。系统以“一个网站项目、一套独立资料与学习记忆”为边界，将关键词研究、竞品正文学习、内容生成、质量审核、GSC 效果观察和 WordPress 发布放在一条可追溯的工作流中。

它不把搜索数据、模型和生成结果伪装成确定答案：每次任务都会保留实际使用的模型、可读来源、失败原因、版本与审批状态。

## 当前能力

### 多网站项目管理

- 创建并管理多个网站项目，按项目隔离关键词、标题、内容、知识库、来源、GSC 数据和 WordPress 配置。
- 项目总览显示关键词、已选标题、内容、资料与近期任务状态。
- 删除项目时级联清理对应数据，避免不同网站之间混入内容或资料。

### 关键词研究与标题选题

- 基于 Google Suggest 扩展种子词，支持语言、国家/地区和递归层级控制。
- 关键词可由规则或 AI 审核，输出搜索意图、相关性、建议动作和审核理由。
- 关键词入库后可直接跳转生成标题；标题候选保留关键词、意图、原因和选定状态。
- 支持基于真实 VOL 与 SERP 指标计算 KD 与机会分；没有真实数据时不会伪造搜索量。

### 竞品内容学习与长期记忆

- 使用 Serper Google 搜索结果优先发现信息型内容页面，自动排除商品页、亚马逊等产品信息页。
- 仅对实际可读取的同行文章做正文采集和分析；robots 屏蔽、抓取失败和跳过原因会明确显示，不会伪造正文。
- 从竞品学习搜索需求、标题写法、结构、关键词覆盖、表达策略和内容缺口，而不是复制原文。
- 支持定期竞品学习计划，把可复用的写法卡、需求洞察和策略沉淀为项目长期记忆。
- 提供学习记忆管理、置顶、启停、人工优先级与“有用 / 不适用”反馈；原始证据保持可追溯。

### 公司知识库与权威来源

- 上传或采集产品、About Us、认证、工厂、案例、FAQ 等网站资料。
- 新资料由 DeepSeek 归纳摘要、标签和分类，再按项目写入知识库。
- 支持手工维护标准、政府、认证、行业研究与第一方资料等权威来源。
- 生成内容时只引入相关且可验证的来源；没有匹配来源时不强行添加“权威参考资料”。

### 内容智能工作流

- 从已选标题创建内容资产，按 `Brief → 大纲 → H2 分章写作 → 全文组装 → QA` 推进。
- 竞品正文、公司知识库、GSC 锚文本和权威来源可作为明确输入；没有依据的具体事实会标记为待验证。
- 保留 Brief、大纲、正文版本、每个阶段的执行日志、模型与失败信息，支持定向重写。
- 支持 ChatGPT、DeepSeek、Gemini；写作和审核模型会自动读取“AI 与集成”页保存的默认模型。
- 自动协作模式固定为 DeepSeek 做分析/审核、ChatGPT 做写作；不会无提示回退到其他模型。

### LangGraph 智能体编排层

- LangGraph 不替代 ChatGPT、DeepSeek 或 Gemini；模型负责分析、写作和审核，LangGraph 负责把这些动作组织成可执行、可恢复、可审计的内容工作流。
- 工作流以 `project_id` 为强制边界，只有当前网站项目的资料、竞品、学习记忆、GSC 数据和内容资产可以进入任务。
- 每个任务保留当前节点、状态、事件、允许调用的服务端工具和错误信息，支持在采集、分析、写作、审核或发布门禁失败后从对应阶段恢复。
- 工具调用采用服务端白名单：读取项目上下文、检索记忆、竞品研究、写法卡提炼、内容规划、文章生成、质量审核和发布准备均有明确边界，不允许智能体任意访问本机或跨项目数据。
- 当前仓库已包含 LangGraph 的基础内容工作流与任务状态模型；后续会逐步把现有内容生产、定期学习、效果评估和发布审批迁入可持久化的工作流节点，而不重写已有前端和业务接口。

### GSC 与发布后学习

- 打开专用 Chrome 后由用户自行登录 Google Search Console；系统不读取密码、Cookie 或浏览器保存的登录信息。
- 可采集美国最近 7 天、平均排名 40 以内的英语查询，并建立“查询词 → 网页 URL”关系用于内链锚文本建议。
- 对已发布文章建立 GSC 表现快照，结合内容 QA、结构、来源和正文深度形成质量/效果观察；样本不足时明确标记为观察中。

### 图片与 WordPress 发布

- 按 H2 生成并插入配图，可使用已配置的图片服务；图片支持 800×600、WebP、SEO 文件名、alt 文本和图注。
- 发布前执行门禁检查：正文、来源、图片、配置和审批状态均可见。
- 可选择创建 WordPress 草稿或直接发布；发布成功后保存 WordPress 文章编号和页面链接。
- WordPress 使用站点后台登录流程；账号需要具备创建文章和上传媒体权限。

## 技术栈

- 前端：React、Vite、TypeScript
- 后端：Python 标准库 HTTP 服务
- 数据库：SQLite
- 智能体编排：LangGraph（项目隔离的内容任务状态与工具调用边界）
- 测试：Python `unittest` 与前端 TypeScript 生产构建
- 本地服务：`http://127.0.0.1:8000`

## 快速启动

```powershell
# 安装并构建前端
cd frontend
npm install
npm run build

# 回到项目根目录，启动后端
cd ..
$env:PYTHONPATH = (Join-Path (Get-Location) 'src')
python -m seo_control serve --host 127.0.0.1 --port 8000
```

打开 <http://127.0.0.1:8000>。

默认 SQLite 数据库保存在 `data/seo-control.sqlite3`。请勿提交其中包含真实网站资料、账号配置或业务数据的副本。

## 配置说明

在“AI 与集成”页面分别保存 ChatGPT、DeepSeek、Gemini 与 Serper 配置。模型配置由服务端安全保存，前端只显示是否已配置；不要将 API Key、WordPress 密码或浏览器登录信息写进源码、文档或 Git。

| 功能 | 数据/模型来源 | 说明 |
| --- | --- | --- |
| 关键词发现 | Google Suggest | 仅用于发现关联词，不代表真实搜索量。 |
| 竞品研究 | Serper Google + 正文采集 | 只学习可读取、相关的内容页面；不复制原文。 |
| 资料整理与竞品学习 | DeepSeek | 用于归纳、分类、写法卡与长期学习记忆。 |
| 内容写作 | ChatGPT（默认 `gpt-5.6-sol`） | 可在内容工作流中切换已配置的模型。 |
| 内容审核 | 跟随写作模型或指定模型 | 审核记录写入内容版本与执行日志。 |
| GSC | 用户已登录的 Chrome 页面 | 系统不读取账号密码、Cookie 或令牌。 |
| WordPress 发布 | 当前项目的站点后台 | 需要该账号具有文章与媒体上传权限。 |

## 运行边界

- 不自动绕过 robots.txt、登录、付费墙或站点访问限制。
- 不伪造 Google 搜索量、竞品正文、权威来源、GSC 数据或发布成功结果。
- 不复制竞争对手文章；系统沉淀的是需求、结构、覆盖和表达策略。
- AI 输出仍需人工审核，尤其是产品参数、法规、安全标准、价格与其他可验证事实。
