## 控制接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/runtime-database/status` | 查看模式、影子统计和最近门禁 |
| POST | `/api/runtime-database/shadow/enable` | 开启影子读取，确认值 `ENABLE_SHADOW_READS` |
| POST | `/api/runtime-database/cutover/check` | 运行完整切换门禁 |
| POST | `/api/runtime-database/cutover` | 通过门禁后切换，确认值 `CUTOVER_TO_POSTGRES` |
| POST | `/api/runtime-database/rollback` | 切回 SQLite，确认值 `ROLLBACK_TO_SQLITE` |

## 运维

- PostgreSQL 重启后运行根目录的 `start-workspace-postgres.ps1` 启动工作台。脚本不会保存或输出数据库密码，并强制校验目标数据库名。
- 需要紧急回滚时运行 `rollback-workspace-sqlite.ps1`；当前服务会立即改用 SQLite，PostgreSQL 数据仍保留。
- 切换后的新增数据只会进入 PostgreSQL。若回滚后需要再次切换，必须先执行 PostgreSQL 同步和完整门禁，不能直接复用旧快照。
- `DATABASE_URL` 单独存在不能绕过门禁；持久状态未批准时，服务会安全回退到 SQLite。
