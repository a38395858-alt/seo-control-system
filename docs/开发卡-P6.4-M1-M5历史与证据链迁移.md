# 开发卡：P6.4 / M1-M5 历史与证据链迁移

状态：已完成（2026-07-31）

## 目标

在 P6.2 项目和 P6.3 关键词/采集入口快照之后，迁移能够证明“数据从哪里来、经过什么任务、形成哪个版本和哪条记忆”的历史明细。迁移必须保持原 ID、项目边界、父子引用、时间、模型、失败原因和证据内容。

## 表与迁移顺序

### 关键词证据链

1. `keyword_research_tasks`
2. `import_batches`、`import_rows`、`suggest_query_jobs`
3. `keyword_categories`
4. `keyword_category_assignments`
5. `keyword_reviews`、`keyword_sources`、`keyword_metric_snapshots`

### 采集与记忆证据链

1. `competitor_catalog_collection_runs`
2. `competitor_content_memory`
3. `competitor_content_chunks`、`competitor_content_versions`
4. `collection_run_items`
5. `competitor_content_learning_runs`
6. `content_learning_memories`
7. `content_learning_memory_sources`、`content_learning_memory_feedback`

## 项目隔离

- 原表已有 `project_id` 时原样迁移。
- 只有父级外键的历史表通过父表推导 `project_id`，并在 PostgreSQL 目标表显式保存。
- 每个快照的校验键为 `<source_table>:<主键>`；复合主键使用冒号连接。
- 目标表全部保存 `project_id`，禁止跨项目查询或写入证据。

## PostgreSQL 依赖

- 必须先完成 `workspace_projects`、`workspace_keywords`、`workspace_competitor_urls`。
- 正文、分块和版本使用独立目标表，不能写回 P6.3 的 URL 目录。
- `memory_id`、`version_id`、`keyword_id` 等使用目标表外键；旧运行中允许为空的引用继续允许为空。
- 记忆的 `superseded_by_id` 属于自引用，为避免批次顺序造成假失败，先保留引用值并在校验报告中比较；最终切换阶段再增加延迟外键。

## CLI

```text
migrate-evidence-postgres [--apply]
validate-evidence-postgres
```

未传 `--apply` 时只读 SQLite，不连接 PostgreSQL。应用顺序由 Repository 固定，不能由模型或前端指定表名。

## 不在本阶段范围

- 标题候选、内容资产、草稿、Agent 节点、审批、WordPress 与 GSC；这些在 P6.5 迁移。
- 不启用双写，不切换 8000 工作台数据源。
- 不让 Agent 直接读取 PostgreSQL、SQLite、迁移命令或任意表。

## 验收标准

- 18 张表都可 dry-run、幂等 apply、逐字段 validate。
- JSON 规范化后比较，不能因为键顺序误报。
- SQLite 无时区文本与 PostgreSQL `TIMESTAMPTZ` 比较一致。
- 缺失、额外和字段不一致报告必须包含表名和主键。
- 项目 ID 推导和跨项目隔离有测试。
- PostgreSQL 不可用不影响 SQLite 工作台。
- 全量 Python 测试、React 构建和真实数据只读预览通过。

## 交付结果

- 新增 `SQLiteEvidenceRepository` / `PostgresEvidenceRepository` 和 `EvidenceMigrationService`，固定按 18 张表的依赖顺序处理。
- 原表无 `project_id` 的 6 类历史记录通过受控 JOIN 推导项目，目标表都显式保存项目边界。
- PostgreSQL apply 使用单连接事务批量 upsert，支持重复执行和自增序列校正。
- validate 按 `<source_table>:<主键>` 报告缺失、额外和字段差异，并规范化 JSON、UTC 秒级时间与数值。
- CLI 已提供 `migrate-evidence-postgres [--apply]` 和 `validate-evidence-postgres`；dry-run 不连接 PostgreSQL。
