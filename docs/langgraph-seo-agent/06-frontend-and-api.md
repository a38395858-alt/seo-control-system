# 模块 6：前端与 API

## 目标

在现有中文 UI 内显示模型选择、任务进度、学习记忆、审批和版本差异；不引入静态演示数据。

## 页面改动

| 页面 | 新增内容 |
|---|---|
| 内容生产 | 写作/审稿模型选择器、内容学习模式、蓝图确认 |
| 内容详情 | 使用的记忆、模型版本链、QA 评分、反馈入口 |
| 竞品学习记忆 | 来源、写法卡、质量分、禁用、被哪些文章采用 |
| 公司知识库 | 是否进入品牌记忆、被哪些文章引用 |
| 系统任务 | 节点时间线、模型、重试、审批与失败原因 |
| 内容发布 | 发布门禁、草稿/公开选项、确认动作、成功 URL |

## API 分层

- `agent-jobs`：创建、读取、重试、取消任务。
- `memories`：列出、禁用、重新分析、查看引用关系。
- `feedback`：保存人工评分和修改意见。
- `approvals`：读取和决定蓝图/发布审批。

所有 API 请求都含 `project_id`；路由项目 ID 与请求体不一致时必须拒绝。

## UI 状态

- 任务运行：显示当前节点、模型和安全可见的进度说明。
- 等待审批：突出显示影响范围和“批准/拒绝”动作，不显示伪成功。
- 失败：展示节点、错误摘要、重试按钮和已完成工作。
- 空状态：提示用户选择项目、配置模型或补充知识库。

## 验收标准

- 1440×1080 与移动端均可完成模型选择、查看任务和确认发布。
- 路由切换后项目上下文正确，数据不泄露。
- 每个 UI 结果都来自 API 真实数据。
