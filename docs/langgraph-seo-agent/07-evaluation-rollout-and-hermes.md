# 模块 7：评测、上线与 Hermes

## 目标

通过固定评测集证明“学习记忆 + GPT/DeepSeek 协作”确实改善内容，再逐步启用 Hermes 网页执行能力。

## Phase 0 基线

选取至少 20 个现有标题/文章，记录当前方案的：生成时长、失败率、模型成本、人工评分、搜索意图匹配、品牌自然度与可发布率。

## 评测维度

`搜索意图、结构深度、具体性、品牌自然度、事实可验证性、原创表达、发布完整性`。

每次更改模型提示词、路由策略或记忆检索规则，都使用同一评测集对比；只有质量不下降且成本/耗时可接受时上线。

## 灰度上线顺序

1. 任务状态与审批骨架。
2. 竞品写法记忆，仅展示，不影响生成。
3. 记忆辅助蓝图，用户确认后生成。
4. GPT/DeepSeek 模型切换与版本对比。
5. 审稿定向重写与发布门禁。
6. GSC 反馈记忆。
7. Hermes 网页执行员。

## Hermes 接入条件

只有在现有 Serper + Python 爬虫无法稳定获得所需结构时才接入。仅开放：

`search_candidates`、`fetch_page`、`extract_structure`、`save_research_result`。

禁止开放 WordPress、数据库、配置文件、密码、删除和公开发布工具。上线前必须与 Python 爬虫比较抓取成功率、成本、耗时、robots 合规性和结果质量。

## 验收标准

- 评测集结果可追溯、可复跑。
- 新流程质量不低于基线，且不出现自动公开发布。
- Hermes 不可用时，竞品研究自动回退到现有 Python 路径。
