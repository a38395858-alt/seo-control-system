# 开发卡：P6.7 PostgreSQL 全库切换演练

状态：已完成（2026-07-31）

## 目标

将 P6.2-P6.6 的 6 批迁移组合为一条可预览、显式确认、失败即停和统一校验的全库演练命令。演练只使用独立 PostgreSQL 数据库，不写现有 `seo_agent` 数据库，不切换 8000 工作台。

## 固定顺序

1. `projects`
2. `keywords`
3. `collection`
4. `evidence`
5. `workflow`
6. `legacy`

任一批连接失败、写入失败或 validate 不通过时，后续批次标记为 `not_run`，不继续冒险写入。

## CLI

```text
migrate-all-postgres
migrate-all-postgres --apply --confirm-full-migration
validate-all-postgres
```

- 不传 `--apply` 时不需要 `DATABASE_URL`，只读 SQLite 并输出六批计数。
- 全库写入必须同时传 `--apply` 和 `--confirm-full-migration`。
- validate 只返回批次计数、缺失/额外主键、mismatch 字段名，不返回正文、JSON 字段值或凭据。
- 目标描述只显示 scheme、host、port 和 database，不显示用户名/密码。
